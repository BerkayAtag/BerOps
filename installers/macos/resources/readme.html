Kurulumdan sonra

Ajanı sunucunuza bağlamak için Terminal'de çalıştırın (değerleri konsoldaki Ajan indir sayfasından alın):

sudo /usr/local/bin/ber-agent configure \
  -server https://ber.ornek.local:52311 \
  -key berreg_... \
  -ca-hash sha256:...

MDM ile dağıtımda yapılandırma io.github.berkayatag.ber.agent tercih alanıyla (Server, RegistrationKey, CAHash) verilebilir.

Kaldırma: sudo /usr/local/bin/ber-agent-uninstall
